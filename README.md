# ❤️ My Favorites

A simple and attractive React web application showcasing my Top 5 Favourite Places, Foods, and Animals.

## 🌟 About the Project

My Favorites is a personal collection of things I love, presented through a clean and visually appealing user interface.

## ✨ Features

- 🌍 Top 5 Favourite Places
- 🍕 Top 5 Favourite Foods
- 🐾 Top 5 Favourite Animals
- 🎨 Attractive and user-friendly design
- 📱 Responsive interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/Tamanna040606/Favorites.git
```

Navigate into the folder:

```bash
cd Favorites
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
